# Интеграция бота в браузерный клиент (безопасно)

Цель: игрок-бот **всегда виден как BOT**, показывает «думает…» во время хода, а **все игровые действия** по-прежнему проходят через **Game Engine**. Браузер **не** должен напрямую дергать `POST /bots/action` в money-режиме с пользовательской сессии.

## Поток данных

1. Браузер подключается к **Game Engine** (REST и/или WebSocket): стол, раздача, чей ход, `legalActions`, банк, карты на борде, свои карты.
2. Когда ход у бота, **Game Engine** (серверная сторона) ставит задачу в **bot-server** (`POST /bots/action` с job) — это не фронтенд игрока.
3. Bot-server считает действие и шлёт предложение обратно в Game Engine (`POST …/internal/bot-action`).
4. Game Engine валидирует ход и рассылает обновлённое состояние всем клиентам.

```text
Browser  <--WS/REST-->  Game Engine  <--internal-->  Bot Server
```

## Что обязан делать UI

- Для каждого места за столом, если `player.isBot === true` (или эквивалент в вашей модели):
  - показывать бейдж **BOT** рядом с ником;
  - не подменять бота на «человеческий» ник без явного `BOT` в интерфейсе.
- Когда `currentActorId` (или seat) совпадает с ботом и сервер ещё не прислал новое состояние после таймера хода:
  - показывать индикатор **«думает…»** (пульсация / скелетон / таймер ожидания).
- Все кнопки **FOLD / CHECK / CALL / BET / RAISE** для **человека** вызывают только **Game Engine**. Бот не кликает по DOM.

## Минимальные поля в состоянии стола (рекомендация)

Чтобы фронтенд мог корректно отрисовать бота и «думает»:

| Поле | Назначение |
|------|------------|
| `players[].id` | Идентификатор игрока |
| `players[].displayName` | Имя (для ботов лучше с префиксом `BOT ` на бэкенде) |
| `players[].isBot` | `true` только для ботов |
| `currentActorId` | Чей сейчас ход |
| `handId`, `street` | Для отладки и анимаций |

Индикатор «думает» логично показывать, когда `currentActorId` указывает на бота **и** с последнего сообщения о смене хода прошло немного времени (например 300–800 мс), чтобы не мигать на каждом кадре.

## Пример: подписка на стол (псевдокод)

Ваш клиент только слушает Game Engine и перерисовывает места:

```javascript
// Не вызывайте bot-server из браузера для money-игры.
socket.on("table:update", (snapshot) => {
  const html = snapshot.players
    .map((p) => PokerBotTableUI.renderSeatCardHtml(p, snapshot))
    .join("");
  seatsRoot.innerHTML = html;
});
```

Где `snapshot` содержит как минимум `players[]` с полями `id`, `displayName`, `isBot` и `currentActorId`.

## Демо в этом репозитории

- Страница: `GET /table-demo` (например `http://127.0.0.1:8000/table-demo` после `docker compose up`).
- Переиспользуемый скрипт: `/static/js/bot-table-ui.js` (глобальный объект `PokerBotTableUI`).

Демо использует **локальный mock-снимок состояния**, чтобы не требовать реальный Game Engine. В продакшене замените источник данных на ваш WebSocket/REST от Game Engine.

## Безопасность

- **Не** встраивайте `SERVICE_TOKEN` и URL внутреннего API bot-server в браузер.
- Панель `/` и `/dashboard` защитите (VPN, Basic Auth, отдельный админ-домен), если она доступна из интернета.
